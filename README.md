# PFAS IMplementor for Mass Spectrometry (PIMMS)

PIMMS is designed to simultaneously identify known and unknown fluorinated chemicals in standards as well as in simple and complex mixtures. PIMMS uses data produced by Liquid Chromatography-Ion Mobility Spectrometry-Mass Spectrometry. It is designed to be an end to end processor as a complete solution to PFAS analysis. Updates are made consistently with an active issues page for community suggestions.
